A make.fun entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

`main.py` (stdlib-only Python) writes one line — a pickup line a vending
machine would use on a passing human — to `/output/entry.txt`. The line is
118 characters, inside the gate's 1–200 character window, and the program is
fully deterministic: every run writes the same bytes.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
